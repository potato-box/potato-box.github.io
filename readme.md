# Інженерні калькулятори — Майстерня

Колекція практичних інженерних калькуляторів та довідкових інструментів для майстерні, виробництва, навчання й щоденної роботи. Усі розрахунки виконуються безпосередньо в браузері без складних налаштувань, а окремі інструменти можна встановити для офлайн-доступу на смартфоні.

## Як скористатися

1. Відкрийте сторінку порталу у браузері на комп’ютері або смартфоні (через GitHub Pages).
2. Оберіть потрібний інженерний напрямок на верхній панелі.
3. Натисніть на обраний калькулятор зі списку, щоб перейти до розрахунку.
4. За потреби перемкніть світлу або темну тему кнопкою **«Тема»** у правому верхньому куті.

> **Важливо:** усі калькулятори мають довідковий характер. Перед реальним монтажем, складанням вузлів або запуском обладнання обов’язково перевіряйте критичні параметри, допуски та вимоги нормативної документації.

## Доступні напрямки та інструменти

* **Електротехніка**
  * Переріз кабелю та падіння напруги
  * Закон Ома та потужність
  * Дільник напруги
* **Механіка**
  * Передавальне число та оберти
  * Момент затягування болтів
  * Крутний момент і потужність
* **Хімія**
  * Розведення розчинів
  * Молярна маса речовини
* **Фізика**
  * Рівноприскорений рух
  * Тепловий баланс та нагрів
* **Математика**
  * Відсотки та пропорції
  * Трикутник і кути
* **Кріплення**
  * Допуски та посадки (ISO)
  * Крок і діаметр різьби
* **Електроніка**
  * Калькулятор ШІМ (PWM)
  * Резистор для світлодіода
* **Конвертери**
  * Тиск та сила
  * Довжина та маса

*(Перелік інструментів поступово розширюється — частина сторінок може перебувати в процесі наповнення).*

## Структура проєкту

Інтерфейс побудовано на чистому HTML, CSS та JavaScript без зайвих залежностей:

* `index.html` — головна сторінка порталу з навігацією за напрямками та перемикачем теми.
* `<напрямок>/<назва-калькулятора>/index.html` — окремі сторінки інструментів за відповідними категоріями.

## Пропозиції та зворотний зв’язок

Якщо ви знайшли неточність у формулах чи розрахунках, помітили помилку або хочете запропонувати новий калькулятор для майстерні — скористайтеся розділом **«Зворотний зв’язок та підтримка»** на сайті або створіть **Issue** у цьому репозиторії.

## Ліцензія

Дивіться умови використання у розділі **«Ліцензія»** на сайті або у файлі ліцензії репозиторію.
